# DevPost workspace

This directory holds the project-planning and learning documents used by the ChallengePost `learn-ai-basics` workflow. It is documentation for the Decraft repository, not application code and not a Devpost submission bundle.

- `learner-profile.md` records project context and collaboration preferences.
- `scope.md` captures the approved product direction and boundaries.
- `prd.md` translates that direction into product requirements and points to the repository's [`PRD.md`](../PRD.md) for the detailed source of truth.
- `spec.md` records the technical design and current implementation state.
- A build checklist may be added here as implementation progresses.

Keep this workspace at the repository root so the planning docs sit alongside the product requirements, solution approach, backend, and frontend. Update `spec.md` when implementation decisions or capability status change; update `prd.md` only when approved product requirements change.
