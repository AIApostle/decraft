# Frontend asset sources

- `public/images/woodshop.jpg` — [Unsplash image](https://images.unsplash.com/photo-1530124566582-a618bc2615dc)
- `public/images/ceramics.jpg` — [Unsplash image](https://images.unsplash.com/photo-1578749556568-bc2c40e68b61)

Fonts are self-hosted webfont files downloaded from Google Fonts for offline-friendly rendering:

- `public/fonts/bodoni-moda-latin.woff2` — Bodoni Moda
- `public/fonts/public-sans-latin.woff2` — Public Sans
- Font license: [SIL Open Font License](https://openfontlicense.org/)
